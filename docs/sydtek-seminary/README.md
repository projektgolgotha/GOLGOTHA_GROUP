# SydTek Seminary — Ethiopian Canon Studies development track

This package develops an 81-entry study pathway within the existing **ECS-300 Certificate in Ethiopian Canon Studies** institutional design. It is a **noncredit curriculum release**. This build does not confer accreditation, degree authority, ordination, or an academic award.

## Start here

- [SEM-000 orientation](SEM-000_ORIENTATION.md): four lessons, activities, a formative study check, and a first portfolio.
- [SEM-101 syllabus and lessons](SEM-101_SYLLABUS_AND_LESSONS.md): the first eight canon entries, selected passage activities, outcomes, and assessment design.
- [Academic program](ACADEMIC_PROGRAM.md): course structure, learning outcomes, assessment approach, workload estimates, and the relationship to the existing program.
- [Unit worksheet](UNIT_WORKSHEET.md): a reusable close-reading and evidence record for every book or component.
- [Canon basis](CANON_BASIS.md): the declared 46 OT + 35 NT numbering convention and textual identity questions.
- [Accreditation pathway](ACCREDITATION_PATHWAY.md): official-source development requirements and institutional gaps.
- [Build chunks](BUILD_CHUNKS.md): implementation sequence, dependencies, and acceptance criteria.

## Portable records

- [`canon-registry.json`](../../content/sydtek-seminary/canon/canon-registry.json): all 81 entries and their component texts.
- [`curriculum-manifest.json`](../../content/sydtek-seminary/canon/curriculum-manifest.json): twelve delivery parts and estimated workload.
- [Source inventory](../../content/sydtek-seminary/sources/README.md): 118 public playlists, one individually identified John video, screenshot evidence, alternate collections, and exact-text review gaps.
