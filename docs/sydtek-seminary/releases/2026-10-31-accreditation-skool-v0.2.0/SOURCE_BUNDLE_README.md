# Locked source bundle

`SydTek_Seminary_v0.2.0_Source_Bundle.tar.gz` contains the complete UTF-8 Markdown, JSON, and checksum sources from the generated accreditation and Skool build package.

SHA-256: `4ac41c7c084a15e136ce0eb8ba4e8e616a9e23ffbde678a9853c167b0e5ec7be`

The bundle includes the ABHE and TRACS planning crosswalks, proposed 48-SH diploma, assessment plan, state-authorization gate, canon reconciliation plan, roadmap, SEM-101/102/103 course sources, and Skool build manifest. Binary workbook and ZIP identities are recorded in `BINARY_ARTIFACTS.json`.

This is a provenance and development snapshot. It does not establish accreditation, state authorization, academic-credit authority, faculty adoption, enrollment, or learner completion.
